Marvin Sim Chair — cheat sheet (updated 2026-10-16)
Full guide: docs\START_TELEOP.md
====================================================

START MARVIN (from the chair PC, ~2 min; wait for "Video: open ...")
  ssh dinosaur@100.93.121.3 "bash ~/SimChair_AVL/jetson/relay_teleop/start_all.sh"
  options before "bash":  FRONT_ONLY=1   START_SCALE=0.4   MAX_SCALE=0.6   NO_IMU=1
  bad daytime link:  FRONT_ONLY=1 START_SCALE=0.4 MAX_SCALE=0.6

  If the team's WebUI launch is running it owns the Teensy too — stop it first
  (with the team's OK):  pgrep -af webui.launch

START CHAIR SIDE
  windows\start_chair.bat      sender (--no-dbox) + IMU Chair + viewer
  viewer: http://100.93.121.3:8090/   ONE viewer only

DRIVE
  park (0) once to arm, then paddle 1 = diff, 2 = Ackermann, 0/3 = off

CHECK / STOP
  ssh dinosaur@100.93.121.3 "tmux list-windows -t simchair"
  ssh -t dinosaur@100.93.121.3 "tmux attach -t simchair"     Ctrl+B N next, Ctrl+B D leave
  ssh dinosaur@100.93.121.3 "bash ~/SimChair_AVL/jetson/relay_teleop/stop_all.sh"
  close the "Marvin Sender (no D-BOX)" and "IMU Chair" windows

CAMERA WON'T OPEN
  ssh dinosaur@100.93.121.3 "bash ~/SimChair_AVL/jetson/relay_teleop/stop_all.sh; sudo systemctl restart nvargus-daemon"
  still failing: power off, reseat that camera's GMSL cable; or FRONT_ONLY=1

DEPLOY CHANGES TO MARVIN (copy, not git)
  scp jetson\<file> dinosaur@100.93.121.3:SimChair_AVL/jetson/<file>
  scp windows\multicam_viewer.html dinosaur@100.93.121.3:SimChair_AVL/windows/

Physical E-stop latches the Spark MAXes; a software restart won't clear it.
